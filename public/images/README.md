# Imagens de Lutas de Taekwondo

Esta pasta contém imagens de lutas e técnicas de taekwondo para serem exibidas na galeria da página inicial.

## Como adicionar imagens:

1. **Formatos suportados**: JPG, PNG, WebP
2. **Tamanho recomendado**: 800x600px ou proporção similar
3. **Otimização**: Use imagens otimizadas para web (menos de 500KB por imagem)

## Estrutura sugerida:

- `lutas/` - Imagens de lutas e competições
- `tecnicas/` - Imagens demonstrando técnicas específicas
- `treinos/` - Imagens de treinos e práticas
- `competicoes/` - Imagens de eventos e competições

## Exemplos de imagens que podem ser adicionadas:

- Chutes em ação (Ap Chagi, Yeop Chagi, Dollyo Chagi)
- Posições de combate
- Competições olímpicas
- Treinos em grupo
- Demonstrações de técnicas
- Faixas coloridas em ação

## Nomenclatura:

Use nomes descritivos em português:
- `chute-frontal-ap-chagi.jpg`
- `competicao-olimpica-2024.jpg`
- `treino-flexibilidade.jpg`
- `luta-faixa-vermelha.jpg`

## Atualização do componente:

Após adicionar as imagens, atualize o array `taekwondoImages` no arquivo `ImageGallery.jsx` com as informações das novas imagens.
